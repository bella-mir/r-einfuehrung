Einheit 3: Daten einlesen, aufräumen & speichern

In Einheit 2 hast du Data Frames selbst erstellt. Meistens liegen Daten aber in Dateien vor und müssen erst aufgeräumt werden. In dieser Einheit lernst du — und wiederholst dabei an echten Daten das Wichtigste aus Einheit 2:

  1. Daten einlesen — CSV- und Excel-Dateien in R laden
  2. Daten aufräumen — Spaltennamen und Texte bereinigen, Kategorien bilden
  3. Daten speichern — als CSV, Excel oder RDS

Für Excel-Dateien brauchen wir zwei Pakete. Falls noch nicht geschehen, einmalig in der Console installieren: install.packages(c("readxl", "writexl")). Geladen werden Pakete am Anfang des Dokuments:

library(readxl)    # Excel-Dateien lesen
library(writexl)   # Excel-Dateien schreiben

In fremden Skripten steht oft install.packages() direkt im Code und require() statt library(). Besser: einmal in der Console installieren, im Dokument mit library() laden — sonst wird bei jedem Durchlauf neu heruntergeladen, und ein fehlendes Paket fällt erst viele Zeilen später auf.

Teil 1: Daten einlesen

Tabellen liegen meist als CSV- oder Excel-Datei vor. Eine CSV-Datei (comma-separated values) ist eine einfache Textdatei: eine Beobachtung pro Zeile, die Spalten durch ein Trennzeichen getrennt.

R sucht Dateien relativ zum Arbeitsverzeichnis — beim Öffnen über r-einfuehrung.Rproj ist das der Projektordner (siehe Vorbereitung):

getwd()

CSV einlesen mit read.csv()

read.csv() liest eine CSV-Datei und gibt einen Data Frame zurück:

gemeinden <- read.csv("data/raw/gemeinden.csv")

gemeinden.csv enthält 28 österreichische Gemeinden: Gemeindekennziffer, Bundesland, Gemeindetyp, Einwohnerzahl, Fläche, Entfernung zur Landeshauptstadt (Luftlinie in km) und den durchschnittlichen Preis für Baugrundstücke (€ pro m²; Quelle: Statistik Austria, bei einer Gemeinde haben wir den Preis entfernt).

Spalten mit $

$ holt eine Spalte als Vektor; mit <- legt man eine neue Spalte an:

mean(gemeinden$einwohner)
[1] 19589.29
gemeinden$dichte <- round(gemeinden$einwohner / gemeinden$flaeche_km2)   # Einwohner pro km²

Auswählen mit [Zeile, Spalte]

Vor dem Komma stehen die Zeilen, nach dem Komma die Spalten; eine leere Seite heißt „alle”:

gemeinden[1, "gemeinde"]                        # Zeile 1, Spalte gemeinde
[1] "Aigen im Ennstal"
head(gemeinden[, c("gemeinde", "einwohner")])   # zwei Spalten
          gemeinde einwohner
1 Aigen im Ennstal      2756
2          Alpbach      2510
3       Eisenstadt     16396
4       Finkenberg      1413
5         Forchach       260
6             Graz    306971

Zeilen filtern heißt: eine Bedingung vor das Komma schreiben. Es bleiben die Zeilen mit TRUE:

gemeinden[gemeinden$einwohner > 50000, c("gemeinde", "einwohner")]
   gemeinde einwohner
6      Graz    306971
7 Innsbruck    132820

Leere Felder in einer Zahlenspalte werden beim Einlesen zu NA — bei Ischgl fehlt der Preis:

gemeinden[is.na(gemeinden$preis_m2), ]
    gkz gemeinde bundesland  typ einwohner flaeche_km2 entfernung_km preis_m2 dichte
8 70608   Ischgl      Tirol Land      1624       103.3            88       NA     16

Kategorien: unique() und table()

unique(gemeinden$typ)          # welche Werte kommen vor?
[1] "Land"   "Stadt"  "Umland"
table(gemeinden$bundesland)    # wie oft?

Burgenland Steiermark      Tirol Vorarlberg

Andere Trennzeichen: sep und dec

read.csv() erwartet , als Trennzeichen und . als Dezimalzeichen. Ein Excel mit deutschen Einstellungen speichert CSV aber mit ; als Trennzeichen und , als Dezimalzeichen (86,4).

data/raw/gemeinden_de.csv enthält dieselben Gemeinden in diesem Format. Mit sep allein bleiben die Dezimalzahlen Text:

nur_sep <- read.csv("data/raw/gemeinden_de.csv", sep = ";")
str(nur_sep)   # flaeche_km2 und preis_m2 sind Text: "86,4"
'data.frame':   28 obs. of  8 variables:
 $ gkz          : int  61203 70501 10101 70908 70810 60101 70101 70608 61019 70513 ...
 $ gemeinde     : chr  "Aigen im Ennstal" "Alpbach" "Eisenstadt" "Finkenberg" ...
 $ bundesland   : chr  "Steiermark" "Tirol" "Burgenland" "Tirol" ...
 $ typ          : chr  "Land" "Land" "Stadt" "Land" ...
 $ einwohner    : int  2756 2510 16396 1413 260 306971 132820 1624 1137 20118 ...
 $ flaeche_km2  : chr  "86,4" "58,4" "42,9" "171,5" ...
 $ entfernung_km: int  110 44 0 35 63 0 0 88 32 68 ...
 $ preis_m2     : chr  "91,4" "514,9" "310,3" "365,9" ...

Erst mit dec erkennt R auch die Dezimalzahlen:

richtig <- read.csv("data/raw/gemeinden_de.csv", sep = ";", dec = ",")
str(richtig)   # jetzt sind beide Spalten Zahlen (num)
'data.frame':   28 obs. of  8 variables:

 $ typ          : chr  "Land" "Land" "Stadt" "Land" ...
 $ einwohner    : int  2756 2510 16396 1413 260 306971 132820 1624 1137 20118 ...
 $ flaeche_km2  : num  86.4 58.4 42.9 171.5 14.3 ...
 $ entfernung_km: int  110 44 0 35 63 0 0 88 32 68 ...
 $ preis_m2     : num  91.4 514.9 310.3 365.9 204.5 ...

Kurzform für genau dieses Format: read.csv2(). Weitere nützliche Argumente:

  • skip = 3 — die ersten 3 Zeilen überspringen (z. B. Info-Zeilen über der Tabelle)
  • header = FALSE — wenn die erste Zeile keine Spaltennamen enthält
  • na.strings = c("", "NA", "-") — welche Einträge als fehlend (NA) gelten
  • fileEncoding = "UTF-8" (oder "latin1") — bei falsch dargestellten Umlauten

Excel einlesen: read_excel()

Excel-Dateien (.xlsx, .xls) liest das Paket readxl. excel_sheets() zeigt die Tabellenblätter, sheet wählt eines aus (Name oder Nummer; ohne Angabe das erste):

excel_sheets("data/raw/gemeinden.xlsx")
[1] "gemeinden"     "bundeslaender"
gemeinden_xlsx <- read_excel("data/raw/gemeinden.xlsx")
bundeslaender  <- read_excel("data/raw/gemeinden.xlsx", sheet = "bundeslaender")
str(gemeinden_xlsx)
tibble [28 × 8] (S3: tbl_df/tbl/data.frame)
 $ gkz          : num [1:28] 61203 70501 10101 70908 70810 ...
 $ gemeinde     : chr [1:28] "Aigen im Ennstal" "Alpbach" "Eisenstadt" "Finkenberg" ...
 $ bundesland   : chr [1:28] "Steiermark" "Tirol" "Burgenland" "Tirol" ...
 $ typ          : chr [1:28] "Land" "Land" "Stadt" "Land" ...
 $ einwohner    : num [1:28] 2756 2510 16396 1413 260 ...
 $ flaeche_km2  : num [1:28] 86.4 58.4 42.9 171.5 14.3 ...
 $ entfernung_km: num [1:28] 110 44 0 35 63 0 0 88 32 68 ...
 $ preis_m2     : num [1:28] 91.4 514.9 310.3 365.9 204.5 ...

Trenn- und Dezimalzeichen spielen hier keine Rolle — Excel speichert Zahlen als Zahlen. skip gibt es auch hier, na.strings heißt na, und range = "A5:D20" liest nur einen Zellbereich.

read_excel() gibt ein Tibble zurück — eine Variante des Data Frames (mehr in Einheit 4). as.data.frame() macht daraus einen gewöhnlichen Data Frame:

gemeinden_xlsx <- as.data.frame(gemeinden_xlsx)

Teil 2: Daten aufräumen

data/raw/bezirke_roh.csv enthält Einwohnerzahl (2021), mittleres Netto-Jahreseinkommen und Fläche von acht Wiener Bezirken (Quelle: Stadt Wien). Für den Kurs haben wir typische Fehler eingebaut: Info-Zeilen, Leerzeichen, ein fehlender Wert.

Einlesen mit den passenden Argumenten

Ein Blick in die Datei zeigt: Semikolon, vier Info-Zeilen, Dezimalkomma und ein Strich für den fehlenden Wert bei Neubau. Das alles erledigt read.csv() gleich beim Einlesen:

bezirke <- read.csv("data/raw/bezirke_roh.csv", sep = ";", dec = ",", skip = 4, na.strings = "-")
str(bezirke)
'data.frame':   8 obs. of  5 variables:
 $ Bezirk.Nummer      : int  1 2 3 4 5 6 7 8
 $ Bezirk.Name        : chr  "Innere Stadt" "Leopoldstadt" "Landstraße" "Wieden  " ...
 $ Einwohner          : int  15867 105237 93248 33075 54373 31336 31683 24365
 $ Mittleres.Einkommen: int  37250 24930 27450 29010 23096 26528 27866 28488
 $ Flaeche.km2        : num  2.87 19.24 7.4 1.78 2.01 ...

Spaltennamen ändern: names()

Leerzeichen in Spaltennamen hat R durch Punkte ersetzt (Bezirk.Nummer). Mit names() und <- vergibst du neue Namen, in der Reihenfolge der Spalten:

names(bezirke) <- c("bezirk_nummer", "bezirk_name", "einwohner", "mittleres_einkommen", "flaeche_km2")

Eine einzelne Spalte: names(bezirke)[2] <- "name".

Text aufräumen und zusammensetzen: trimws(), paste(), substr()

Überflüssige Leerzeichen sieht man in der Tabelle nicht — aber ein Vergleich findet nichts:

bezirke[bezirke$bezirk_name == "Wieden", ]   # kein Treffer
[1] bezirk_nummer       bezirk_name         einwohner           mittleres_einkommen flaeche_km2        
<0 rows> (or 0-length row.names)
bezirke$bezirk_name[4]                       # in der Datei steht "Wieden  "
[1] "Wieden  "

trimws() entfernt Leerzeichen am Anfang und Ende:

bezirke$bezirk_name <- trimws(bezirke$bezirk_name)
bezirke[bezirke$bezirk_name == "Wieden", ]
  bezirk_nummer bezirk_name einwohner mittleres_einkommen flaeche_km2
4             4      Wieden     33075               29010        1.78

paste() verbindet Text mit Leerzeichen, paste0() ohne. substr(text, start, stop) schneidet Zeichen nach Position heraus — z. B. um Codes zu zerlegen:

bezirke$label <- paste0(bezirke$bezirk_nummer, ". ", bezirke$bezirk_name)
head(bezirke$label, 3)
[1] "1. Innere Stadt" "2. Leopoldstadt" "3. Landstraße"  
substr(c("AT130", "AT127"), 1, 2)   # "AT" — das Land
[1] "AT" "AT"

Zahlen in Kategorien einteilen: cut()

cut() teilt eine Zahlenspalte anhand von Grenzen (breaks) in Kategorien und liefert einen Faktor (Einheit 2):

bezirke$groesse <- cut(bezirke$einwohner,
                       breaks = c(0, 30000, 60000, Inf),
                       labels = c("klein", "mittel", "groß"))
table(bezirke$groesse)

 klein mittel   groß 
     2      4      2

Zeilennamen: rownames()

Manche Funktionen (etwa Distanzen und Clusteranalysen) beschriften ihre Ergebnisse mit den Zeilennamen. rownames() setzt sie aus einer Spalte:

rownames(bezirke) <- bezirke$bezirk_name
bezirke["Wieden", c("einwohner", "flaeche_km2")]
       einwohner flaeche_km2
Wieden     33075        1.78

Zeilen mit fehlenden Werten entfernen: na.omit()

na.rm = TRUE lässt NA in einer Rechnung weg. na.omit() entfernt jede Zeile, in der irgendwo ein NA steht — deshalb vorher nur die benötigten Spalten auswählen:

nrow(na.omit(bezirke))                                              # 7 — Neubau fehlt die Fläche
[1] 7
nrow(na.omit(bezirke[, c("einwohner", "mittleres_einkommen")]))     # alle 8 bleiben
[1] 8

Teil 3: Ergebnisse speichern

Bereinigte Daten gehören nach data/processed/ — data/raw/ bleibt unverändert.

# CSV — zum Weitergeben; row.names = FALSE: keine Extraspalte mit Zeilennummern
write.csv(bezirke, "data/processed/bezirke_clean.csv", row.names = FALSE)

# Excel — für alle ohne R; eine benannte Liste ergibt mehrere Tabellenblätter
write_xlsx(bezirke, "data/processed/bezirke_clean.xlsx")
write_xlsx(list(bezirke = bezirke, gemeinden = gemeinden), "data/processed/kursdaten.xlsx")

# RDS — R-Format: behält Datentypen und Faktor-Stufen exakt
saveRDS(bezirke, "data/processed/bezirke.rds")
bezirke <- readRDS("data/processed/bezirke.rds")

CSV und Excel verlieren Faktor-Stufen: Beim erneuten Einlesen ist groesse nur noch Text. RDS-Dateien kann dafür nur R lesen. Mehrere Objekte auf einmal speichert save(a, b, file = "x.RData"), load("x.RData") holt sie zurück.

Faustregel: CSV oder Excel zum Weitergeben, RDS als Zwischenstand für die eigene Weiterarbeit in R.

Einheit 4: Daten auswerten & visualisieren

In dieser Einheit lernst du:

  1. Datenbearbeitung mit dplyr — filtern, sortieren, neue Spalten berechnen, gruppieren, verbinden, umformen
  2. Visualisierung mit ggplot2 — Grafiken schichtweise aufbauen

Falls noch nicht geschehen, einmalig in der Console installieren: install.packages(c("dplyr", "tidyr", "ggplot2")).

library(dplyr)     # Daten bearbeiten
library(tidyr)     # Tabellen umformen
library(ggplot2)   # Grafiken

Wir arbeiten mit den Gemeinde-Daten aus Einheit 3 (bei Ischgl fehlt der Preis — darauf kommen wir mehrmals zurück):

gemeinden     <- read.csv("data/raw/gemeinden.csv")
bundeslaender <- read.csv("data/raw/bundeslaender.csv")

Es gibt zwei Schreibweisen, die sich in diesem Kurs gleich verhalten: %>% (kommt mit dplyr, steht in den meisten Büchern) und |> (seit R 4.1 eingebaut). Du solltest beide lesen können. Tastenkürzel: Strg/Cmd + Shift + M.

mutate() — neue Spalten berechnen

mutate() berechnet eine neue Spalte für jede Zeile — wie gemeinden$dichte <- ... in Basis-R:

gemeinden <- gemeinden %>%
  mutate(dichte = round(einwohner / flaeche_km2))

case_when() — Werte nach Bedingungen einteilen

Jede Zeile in case_when() hat die Form bedingung ~ ergebnis; die erste zutreffende gewinnt, TRUE ~ fängt alles Übrige auf:

gemeinden <- gemeinden %>%
  mutate(preisniveau = case_when(
    is.na(preis_m2) ~ NA,          # fehlende Werte zuerst abfangen
    preis_m2 > 400  ~ "hoch",
    preis_m2 > 100  ~ "mittel",    # alles über 400 ist schon "hoch"
    TRUE            ~ "niedrig"    # alle übrigen Zeilen
  ))

filter(gemeinden, gemeinde == "Ischgl")
    gkz gemeinde bundesland  typ einwohner flaeche_km2 entfernung_km preis_m2 dichte preisniveau
1 70608   Ischgl      Tirol Land      1624       103.3            88       NA     16        <NA>

Ohne die erste Zeile würde Ischgl als "niedrig" eingestuft — die Vergleiche ergeben NA, und dann greift TRUE ~.

count() zählt, wie oft jeder Wert vorkommt — das dplyr-Gegenstück zu table():

HinweisWas ist ein Tibble?

Viele Funktionen aus dplyr, tidyr und readxl geben ein Tibble zurück — einen Data Frame mit anderer Anzeige: Oben stehen Größe und Datentypen (<chr>, <dbl>), gezeigt werden nur die ersten zehn Zeilen (alles: View()). Ein Unterschied beim Arbeiten: tabelle[, "spalte"] liefert bei einem Tibble eine Tabelle, tabelle$spalte immer einen Vektor. as.data.frame() wandelt um.

Datensätze verbinden: Joins

bundeslaender enthält zu jedem Bundesland die Region (Ost-, Süd- oder Westösterreich). Ein Join hängt sie über die gemeinsame Spalte bundesland an gemeinden an.

Die Tabellen passen absichtlich nicht perfekt zusammen: Vorarlberg (Gemeinde Viktorsberg) fehlt in bundeslaender, Salzburg hat keine Gemeinden im Datensatz.

nrow(left_join(gemeinden, bundeslaender, by = "bundesland"))    # 28 — alle Gemeinden, Viktorsberg mit Region NA
[1] 28
nrow(inner_join(gemeinden, bundeslaender, by = "bundesland"))   # 27 — Viktorsberg fällt weg
[1] 27
nrow(full_join(gemeinden, bundeslaender, by = "bundesland"))    # 29 — dazu Salzburg ohne Gemeinde
[1] 29

right_join() behält alle Bundesländer. Meist will man keine Zeilen verlieren, deshalb ist left_join() der Standard:

gemeinden_join <- gemeinden %>%
  left_join(bundeslaender, by = "bundesland")

gemeinden_join %>% filter(is.na(region))
    gkz    gemeinde bundesland    typ einwohner flaeche_km2 entfernung_km preis_m2 dichte preisniveau region
1 80422 Viktorsberg Vorarlberg Umland       441        12.5            23    523.8     35        hoch   <NA>

Über mehrere Spalten: by = c("spalte1", "spalte2"). In Basis-R heißt der Join merge().

Breite und lange Tabellen: pivot_longer() und pivot_wider()

  • breit: eine Spalte pro Jahr. Gut zum Lesen, aber das Jahr steckt im Spaltennamen — R kann nicht danach filtern oder gruppieren.
  • lang: eine Zeile pro Region und Jahr. Das Jahr ist eine eigene Spalte, mit der filter(), group_by() und ggplot2 arbeiten können.

Faustregel: Stehen in den Spaltennamen Werte (Jahre, Monate, Kategorien), ist die Tabelle breit.

Beispiel: ein Export aus der ARDECO-Datenbank mit der Bevölkerung europäischer Staaten und ihrer NUTS-3-Regionen — die Quelle auch für Übungsaufgabe 1. Jedes Jahr ist eine Spalte; weil Spaltennamen nicht mit einer Ziffer beginnen dürfen, hat read.csv() ein X davorgesetzt:

bev_breit <- read.csv("data/raw/ardeco_bevoelkerung.csv")

pivot_longer() macht aus vielen Spalten zwei: eine für die bisherigen Spaltennamen (names_to, im Bild orange) und eine für die Werte (values_to, blau). cols wählt die Spalten aus — wie bei select():

bev_lang <- bev_breit %>%
  pivot_longer(cols = starts_with("X"), names_to = "jahr", values_to = "einwohner",
               names_prefix = "X") %>%          # das X vor der Jahreszahl entfernen
  mutate(jahr = as.integer(jahr)) %>%           # "1960" (Text) -> 1960 (Zahl)
  select(TERRITORY_ID, NAME_HTML, jahr, einwohner)

bev_lang %>%
  filter(TERRITORY_ID %in% c("AT", "AT130"), jahr %in% c(1960, 1990, 2020)) %>%
  pivot_wider(names_from = jahr, values_from = einwohner, names_prefix = "einwohner_")

Teil 2: Visualisierung mit ggplot2

Die Daten vorbereiten

Ohne Preis kann ggplot keinen Punkt zeichnen und warnt bei jeder Grafik. Deshalb entfernen wir Ischgl einmal vorab und geben typ eine sinnvolle Reihenfolge (Faktor, Einheit 2) — sonst wird alphabetisch sortiert:

gemeinden_plot <- gemeinden_join %>%
  filter(!is.na(preis_m2)) %>%
  mutate(typ = factor(typ, levels = c("Stadt", "Umland", "Land")))

Der Grundaufbau

ggplot2 baut Grafiken schichtweise mit + auf:

ggplot(daten, aes(x = ..., y = ...)) +   # Daten + welche Spalte auf welche Achse
  geom_...()                             # welche Form: Punkte, Balken, Linien …

Streudiagramm: geom_point()

ggplot(gemeinden_plot, aes(x = entfernung_km, y = preis_m2)) +
  geom_point(color = "steelblue", size = 2) +
  labs(title = "Baugrundstückspreis nach Entfernung zur Landeshauptstadt",
       x = "Entfernung (km, Luftlinie)", y = "Preis (€ pro m²)") +
  theme_minimal()

Die Punkte streuen stark — ein klarer Zusammenhang ist noch nicht zu erkennen.

Nach Gruppe einfärben

Eine Spalte in aes() auf color legen — Farben und Legende kommen automatisch:

ggplot(gemeinden_plot, aes(x = entfernung_km, y = preis_m2, color = bundesland)) +
  geom_point(size = 2) +
  labs(title = "Preis nach Entfernung, eingefärbt nach Bundesland",
       x = "Entfernung (km, Luftlinie)", y = "Preis (€ pro m²)", color = "Bundesland") +
  theme_minimal()

Jetzt wird das Muster sichtbar: In Tirol und Vorarlberg ist Bauland viel teurer als im Burgenland und in der Steiermark; dort sinkt der Preis mit der Entfernung.

color = "steelblue" außerhalb von aes() setzt eine feste Farbe; color = bundesland innerhalb von aes() färbt nach den Werten einer Spalte.

Balkendiagramme: geom_bar() und geom_col()

geom_bar() braucht nur x und zählt selbst die Zeilen pro Kategorie (hier ohne Ischgl):

ggplot(gemeinden_plot, aes(x = bundesland)) +
  geom_bar(fill = "steelblue") +
  labs(title = "Anzahl Gemeinden pro Bundesland", x = "Bundesland", y = "Anzahl") +
  theme_minimal()

Steht die Balkenhöhe schon in einer Spalte, nimmt man geom_col() (in älteren Skripten: geom_bar(stat = "identity")). dplyr und ggplot2 greifen ineinander: erst die Kennzahl berechnen, dann direkt weiterreichen. reorder(region, preis_mean) sortiert die Balken nach dem Wert, coord_flip() dreht die Grafik:

gemeinden_plot %>%
  filter(!is.na(region)) %>%
  group_by(region) %>%
  summarise(preis_mean = mean(preis_m2)) %>%
  ggplot(aes(x = reorder(region, preis_mean), y = preis_mean)) +
  geom_col(fill = "steelblue") +
  coord_flip() +
  labs(title = "Durchschnittlicher Baugrundstückspreis pro Region",
       x = "Region", y = "Ø Preis (€ pro m²)") +
  theme_minimal()

Kommt eine zweite Gruppe auf fill, werden die Balken gestapelt; position = "dodge" stellt sie nebeneinander:

gemeinden_plot %>%
  filter(!is.na(region)) %>%
  group_by(region, typ) %>%
  summarise(preis_mean = mean(preis_m2)) %>%
  ggplot(aes(x = region, y = preis_mean, fill = typ)) +
  geom_col(position = "dodge") +
  labs(title = "Durchschnittlicher Baugrundstückspreis nach Region und Gemeindetyp",
       x = "Region", y = "Ø Preis (€ pro m²)", fill = "Gemeindetyp") +
  theme_minimal()

Zeitverläufe: geom_line()

geom_line() braucht das lange Format — das Jahr als eigene Spalte, wie in bev_lang. Die Werte nach 2024 sind Prognosen:

bev_lang %>%
  filter(TERRITORY_ID == "AT", jahr <= 2024) %>%
  ggplot(aes(x = jahr, y = einwohner / 1000000)) +
  geom_line(color = "steelblue", linewidth = 1) +
  labs(title = "Bevölkerung Österreichs, 1960–2024",
       x = "Jahr", y = "Einwohner (in Millionen)") +
  theme_minimal()

Mehrere Linien: eine Spalte auf color legen, z. B. aes(..., color = NAME_HTML).

Teilgrafiken: facet_wrap()

facet_wrap(~spalte) zeichnet eine Teilgrafik pro Ausprägung, alle mit denselben Achsen (eigene Achsen: scales = "free"):

ggplot(gemeinden_plot, aes(x = entfernung_km, y = preis_m2)) +
  geom_point(color = "darkred") +
  facet_wrap(~bundesland) +
  labs(title = "Preis nach Entfernung, aufgeteilt nach Bundesland",
       x = "Entfernung (km, Luftlinie)", y = "Preis (€ pro m²)") +
  theme_bw()
